Sistema de Persistência de Informações de Companhias Abertas

Descrição do Projeto
Este projeto consiste na criação de um sistema em Python que persiste informações sobre companhias abertas em um banco de dados SQL e permite consultar essas informações posteriormente. As informações podem variar de uma data para outra, como o nome da empresa (DENOM_SOCIAL) e a situação (SIT). O usuário poderá acessar informações para uma determinada data, seja ela atual ou passada, desde que a informação exista ou tenha sido alterada.

Fonte de Dados
As informações sobre as companhias abertas podem ser obtidas no seguinte link: https://dados.gov.br/dados/conjuntos-dados/cias-abertas-informao-cadastral
